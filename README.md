# Лабораторна робота №10 — Bang & Olufsen

Nothing — Product Landing Page

Адаптивний, продуктивний лендінг для бренду Nothing, створений за методологією ITCSS на базі Vite, Pug та SCSS.

Особливості проєкту

Pixel-Perfect та адаптивність: Повна відповідність макету на мобільних пристроях (320px+), планшетах (768px+) та десктопах (1260px+).

Безшовний фіксований Header: Синхронізоване позиціонування фонового зображення шапки з першим екраном (Hero) без візуальних розривів під час прокрутки, а також інтерактивні hover-стани для контакту (+1 234 555-55-55) та бургер-меню.

Оптимізація зображень: Автоматична генерація адаптивних зображень (360w, 720w, 1440w) у сучасних форматах AVIF, WebP та JPEG за допомогою sharp.

Чиста CSS-інтерактивність: Бургер-меню, стани наведення на картки товарів, плавний скрол та фокус-стани для доступності (a11y) реалізовані без зайвого JavaScript.

ITCSS-архітектура: Чітке розділення стилів на шари (Settings, Tools, Generic, Elements, Objects, Components, Utilities) для зручної підтримки та масштабування.

Стек технологій

Збірка: Vite

Шаблонізатор: Pug

Препроцесор стилів: SCSS (Sass) + ITCSS

Обробка зображень: Sharp

Встановлення та запуск

1. Клонування репозиторію та встановлення залежностей

git clone <URL-вашого-репозиторію>
cd <назва-папки-проєкту>
npm install


2. Оптимізація зображень

Якщо ви додали або оновили вихідні зображення в папці src/assets/raw-images/, запустіть генерацію оптимізованих файлів у public/images/:

npm run images


3. Запуск локального сервера розробки

npm run dev


Після запуску сайт буде доступний за адресою http://localhost:5173 (або іншим портом, вказаним у терміналі). Щоб зупинити сервер, натисніть Ctrl + C.

4. Збірка для продакшену

npm run build


Готові файли для деплою будуть збережені в директорії dist/.овий шлях `/landing-bang-olufsen/`. `node_modules` та `dist` виключено з репозиторію, `package-lock.json` збережено.
